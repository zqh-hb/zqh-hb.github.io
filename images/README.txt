# 网页图片说明

当前版本的 `index.html` 只使用 3 张图片，请将它们放在本文件所在的 `images` 文件夹中。

## 需要准备的图片

### 1. avatar.jpg

- 用途：个人主页头像
- 当前尺寸：1080 × 1078 像素
- 说明：已经接近正方形，页面会显示为圆形头像

### 2. beijing-main.jpg

- 用途：北京页面的主图
- 当前尺寸：1280 × 1680 像素
- 说明：竖版图片，页面会完整显示，不会拉伸变形

### 3. ustc-main.jpg

- 用途：中国科学技术大学页面的主图
- 当前尺寸：1279 × 1706 像素
- 说明：竖版图片，页面会完整显示，不会拉伸变形

## 图片路径

```text
images/avatar.jpg
images/beijing-main.jpg
images/ustc-main.jpg
```

## 注意事项

1. 文件名必须完全一致，包括大小写和文件扩展名。
2. 不要修改 `index.html` 中的图片路径。
3. 单张图片建议控制在 500KB 以内，避免网页加载过慢。
4. 优先使用自己的照片或可商用图片，使用网络图片时请注意版权。
5. 如果暂时没有图片，可以先准备同名占位图片，之后再替换。
